# Radio intelligente 1.14

Base : sources originales 1.11, commit Wokgui/Radio-intelligente 059a7aaa65c771060e7aec36367b40004af5b42c.

Correctifs : fenêtre Android avec marges réelles des barres système, encoche et clavier ; navigation fixe ; contenu défilant ; paysage en deux colonnes ; sélecteurs des modes Musique/Radio compatibles avec le nouveau conteneur. Le CSS de base est inclus localement.

Identifiant conservé : app.radiointelligente. Clés de stockage inchangées. Aucune clé de signature privée dans ces sources.

La signature du fichier 1.11 installé sur le téléphone doit être identique à la clé utilisée pour installer une mise à jour. L’ancien APK 1.10 du bureau est signé avec une autre clé : ne pas désinstaller une version contenant des données pour contourner un refus de signature.

Le profil android-window-profile.json est partagé avec Interface Studio 6.92. Les marges sont mesurées par WindowInsets sur Android ; leurs valeurs usuelles sont déclarées pour la simulation locale. Les mesures réelles du téléphone restent prioritaires.
